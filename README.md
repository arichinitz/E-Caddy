# E-Caddy
Created throughout my sophomore year of high school, the E-Caddy is an automated golf bag that can track the golfers distance from the bag to the hole. Then the bag suggests which club to use by pushing out a club (think Caddyshack), based on the golfer's personalized range of distances.

## Why I Built the E-Caddy

## Problem
Solves two problems in one bag
- Golfers' golf bags are disorganized - golfers cannot find the right club for the right shot on the course
- Inexperienced golfers do not know which club to use at which time
## Features
- GPS Tracking: the bag calculates the distance from the golfer's hole to the bag
- Pop-up Club Recommendation: using linear actuators, the bag pushes out a suggested club based on the golfers personalized swing distances and the distance from the hole

## Tools Used
- Fusion360
- Arduino IDE

## How to Use
The user/golfer inputs their distances (how far they swing each club) and presses the red button to calculate the distance. Once the ball has gone in the hole, the golfer presses the black button to move onto the next hole
## Results
The calculated distance from the golf bag to the hole was accurate, with a 5-yard error
